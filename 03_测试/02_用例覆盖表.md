### 匿名与重复设置决策表

两次为不同 key 的独立提交，不是同 key 网络重试。并发时检查结果集合，不限定哪次请求先成功。

| REPEAT-01 子组合 | anonymous | allowRepeat | 预期两次结果 | 预期答卷／参与记录 | 身份断言与现有映射 |
|---|---|---|---|---|---|
| A | true | false | 201、409 ALREADY_SUBMITTED | 1／1 | `A::test_anonymity_and_repeat_policy_keep_records_consistent` 对应参数；答卷无respondentId，参与只有允许字段 |
| B | false | false | 201、409 ALREADY_SUBMITTED | 1／1 | 同一函数对应参数；答卷关联当前用户，参与与具体答卷无直接引用 |
| C | true | true | 201、201 | 2／0 | 同一函数对应参数；两份答卷均省略respondentId，key不同 |
| D | false | true | 201、201 | 2／0 | 同一函数对应参数；两份答卷均关联当前用户，key不同 |

子组合不是 pytest node ID，实际参数 ID 以报告为准。匿名测试证明字段与引用分离，不保证管理员无法借助时间或日志推断身份。
