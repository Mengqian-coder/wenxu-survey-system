## 已实现能力

| 功能 | 当前行为 |
|---|---|
| 历史版本 | 分页查看、归档筛选、展示操作来源和内容来源版本，并可打开来源版本 |
| 版本恢复 | 草稿选用旧版不创建版本；所有者恢复旧内容生成新版本，保留来源和全部历史 |
| 共享授权 | 向精确匹配的已注册用户名授权整道题，覆盖已有历史及未来版本 |
| 撤销与重新授权 | 复用同一共享记录；所有者管理授权，接收者不能修改或转授原题 |
| 接收者独立副本 | 另存后产生本人拥有的新题目，可管理、创建版本并继续共享；原题撤权不收回副本 |
| 引用查询 | 所有者查看引用问卷总数及自己的问卷明细；其他用户的问卷只贡献数量 |
| 个人题库 | 创建、修改、分页浏览、删除；同题可分类到多个题库，不复制题目 |
| 分类成员 | 加入、移出、分页浏览；撤权后只显示不可用占位，仍可移出分类 |
| 从题库组卷 | 先选择题库和可使用的题目，再选择正式版本；同卷同题最多一次 |

所有正式版本内容保持不可覆盖。归档题目仍可查看和整理分类，新增组卷仍受题目及版本可使用状态限制。恢复旧版不会自动取消父题归档，不会自动替换已有问卷的引用。

独立副本保留来源题目和精确来源版本的定位信息；来源的查看仍受当前授权约束，不能从副本展开未经授权的原题内容。

## 界面流程

1. “我的题目”按本人、共享给本人或全部可访问范围筛选。打开题目后查看历史和来源。
2. 所有者在“共享管理”输入已注册用户的完整用户名，确认整题授权；可以查看有效、已撤销或全部授权，并撤销、重新授权。
3. 接收者可以查看、选用历史或未来版本，也可另存为本人独立题目；原题的编辑、恢复、归档、授权和引用明细入口只向所有者开放。
4. 所有者在“引用查询”查看总数和自己的问卷明细。共享题目不授予其他用户问卷或答卷的访问权限。
5. 在“我的题库”管理分类，或从题目详情加入已有题库。分类成员不可用时不展示题干、作者、版本或原因，只保留移除入口。
6. 问卷选题可以切换到题库入口。选定题目后仍需选择具体版本，题目更新不会自动改变问卷内容。

删除题库只删除容器及分类关系，题目、版本、共享、问卷引用和答卷继续保留。

## 权限和并发

- 共享接收者不得为原题创建版本、恢复、归档、授权或撤权；管理接口统一按资源不存在返回 404。
- 撤权限制新增使用，不遍历改写问卷或独立副本。已经保存的草稿引用可以继续调整必答、顺序及合法跳转并发布；换版、更换实例 ID、删除保存后重加需重新鉴权。
- 新增使用、分类加入与撤权通过题目主档真实递增的 `guardRevision` 协调。撤权先提交则新增操作失败；新增引用先提交则作为已有引用保留。
- 题库成员增删不递增公开元数据修订号；成员变更与删除题库通过题库主档的真实写入协调，避免删除后留下孤立分类。
- 引用查询按不同问卷计数，覆盖草稿、已发布和关闭状态；未迁移的 v1 以及独立副本不算原题直接引用。汇总计数与可见明细从同一次聚合输入生成，明细分页不改变汇总数量。

## 幂等与接口

本轮增加共享、撤权和 8 项题库接口，全部管理写统一沿用原 `Idempotency-Key` 协议，目前共 17 项管理写操作。题库删除的原查询修订号也参与请求摘要；无请求体的 PUT/DELETE 明确拒绝夹带 JSON。

同键同参数先重放原成功回执，再进行新的管理操作。即使原题后来撤权、共享重新授权，或题库已经删除，重放也不会重新执行业务、改变当前权限或复活资源。前端保留未确认操作的原键和参数，确认后打开当前资源；删除题库的确认结果返回题库列表。

用户名按照注册时的 NFKC、去首尾空白和大小写规则精确匹配，不提供模糊用户目录。规范化后的身份键直接用于查询，支持大小写转换后长度扩展的合法 Unicode 用户名。

应用版本为 `2.1.0`；[当前接口快照](附件/openapi-v2-management.json)从应用导出，包含 38 项操作和 85 个类型定义，已通过 OpenAPI 3.1 校验并与应用实时生成结果核对一致。完整目标接口仍见原草案，跨问卷统计和旧问卷显式迁移工具尚不在本轮范围。
