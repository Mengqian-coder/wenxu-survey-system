# 问序前端设计

## 1 页面与结构

前端使用 React、React Router、Vite、JavaScript 与 CSS，采用 Lucide 图标。管理页使用工作空间外壳，填写页使用独立外壳。

| 路由 | 页面 | 主要任务 |
|---|---|---|
| `/login`、`/register` | 登录、注册 | 认证后返回原目标页，仅接受本站内部返回路径 |
| `/` | 我的问卷 | 分页、搜索、按状态筛选 |
| `/surveys/new` | 新建问卷 | 设置问卷信息、题目和跳转 |
| `/surveys/:id/edit` | 编辑管理 | 保存、发布、复制链接和关闭 |
| `/survey/:publicId` | 填写问卷 | 介绍、逐题填写、确认与成功四个阶段 |
| `/surveys/:id/results` | 答卷统计 | 整卷/单题统计及原始答卷 |

所有问卷页面需要登录；未登录访问分享链接时先登录，成功后回到原问卷。

## 2 视觉与可用性

暖白背景 `#f7f8fc`、白色卡片、深灰文字与靛蓝主色 `#4f46e5` 构成界面。主操作用实色按钮，辅助操作用描边或文字按钮；关闭等操作使用确认对话框。

- 状态同时显示文字与颜色；加载、空数据、无权限、失败和已关闭分别提示。
- 编辑器采用“大纲 + 题目卡片”，填写页逐题推进，结果页区分统计与原始答卷。
- 小屏幕导航折叠，题目和统计内容改为单列。
- 表单提供关联标签、可见焦点及键盘操作；对话框限制焦点并支持 Escape，样式响应减少动画偏好。

## 3 编辑器交互

[Editor.jsx](../../01_代码/frontend/src/pages/Editor.jsx) 分别维护服务器问卷、当前表单和保存基线；表单偏离基线时提示未保存。保存期间限制继续修改，成功后采用服务器返回的规范化结果更新基线。新建后进入正式编辑路由，直接发布时先保存再发布。

[editor-utils.js](../../01_代码/frontend/src/editor-utils.js) 将控件中的数字字符串转换为严格数字，省略未设置的上下限。题目、选项和规则使用稳定 ID；错误集中展示并可定位题目，字符数按 Unicode 码点计算。

更换题型前确认，保留题干、说明、必答与题目 ID，重置不适用配置。删除选项、删除或移动题目会先提示对跳转的影响，确认后清理失效规则；规则 ID 的引用同时包含所属题目 ID，避免跨题误删。规则可上移、下移，顺序表示优先级。

界面按问卷状态锁定字段。编辑、发布和关闭携带当前 `revision`；冲突时保留输入，由用户确认后重载。截止控件按设备时区显示，提交带时区的 ISO 时间。未保存时离开或刷新会提醒，但不提供自动保存或恢复。

## 4 填写与结果交互

[Fill.jsx](../../01_代码/frontend/src/pages/Fill.jsx) 在介绍页说明匿名、重复填写、截止和不自动保存规则。开始后保存本次填写凭据，每题继续时采用服务端预览返回的规范化答案和路径。

[fill-utils.js](../../01_代码/frontend/src/fill-utils.js) 比较规范化答案：文本首尾空白、多选排列和等值数字不视为改变。仅返回查看保留后续答案；实际修改前题并继续时发送 `changedQuestionId`，同步清空后续本地输入，再按新路径填写。

首次提交固定凭据与答案快照；网络错误或结果不明确时锁定修改，提供“重试原提交”。422 校验错误允许修正；成功后显示完成页，允许重复时可主动“再填一份”。登录过期可在原页用原账号重新登录；未提交答案与填写凭据仅在本页内存中保留。

[Results.jsx](../../01_代码/frontend/src/pages/Results.jsx) 展示选项计数、占比、数字均值和分页内容。占比以单题有效回答数为分母，多选占比之和可超过 100%；允许重复时显示答卷份数。原始答卷按实际路径展示，匿名答卷不展示账号。

## 5 请求与状态管理

[api.js](../../01_代码/frontend/src/api.js) 集中处理 `/api` 请求、Bearer 凭据、超时和业务错误；页面不直接访问数据库。登录凭据保存在 `sessionStorage`，退出时清除。后端是权限、校验与保存结果的最终依据。

接口字段见 [API 说明](../03_API说明.md)，业务算法见 [关键逻辑说明](../04_关键逻辑说明.md)，构建运行见 [项目 README](../../README.md)。
