# 跨问卷统计实现说明

实现日期：2026-10-23；交付版本：2.2.0。规则依据：[业务规则第 6 节](06_新版业务规则.md)、[接口设计](08_新版接口设计.md)。完整测试结果见[测试说明](../03_测试/README.md)，运行步骤见[项目 README](../README.md)。

## 使用流程

1. 登录后打开导航中的“跨问卷统计”。目录只列出本人新版问卷实际引用过的题目，支持题干搜索和分页；没有答卷的草稿也会出现在目录中。
2. 选择题目，再选择本人问卷使用过的精确版本。页面展示该版本覆盖的问卷数、提交答卷数、有效回答数和未回答数。
3. 单选、多选查看选项次数及比例；数字题查看最小值、最大值、均值及原始数字；文本题分页查看原文。原值按提交时间倒序，同一时间按答卷 ID 倒序，每页最多 100 条。
4. “我的题目”详情及单份问卷结果页也提供对应精确版本的统计入口。源题有多个版本时，切换版本后重新汇总，互不混算。

## 范围与计数

| 事项 | 已实现规则 |
|---|---|
| 数据范围 | 当前登录用户创建的 `schemaVersion=2` 问卷，包括草稿、已发布和已关闭状态；只计算成功提交的答卷 |
| 题目身份 | 按 `questionId + versionId` 精确分组，不按题干或内容相同合并 |
| 历史与恢复 | 直接选用旧版仍统计在旧版；恢复生成的新版本单独统计 |
| 独立副本 | 新身份单独统计，不并入来源题目 |
| 回答映射 | 每份问卷通过自己的卷内题目 ID 找到答案，不把库级 ID 当作答案字段 |
| 未回答 | 留空或被跳过均不计入有效回答；未回答数为提交答卷数减有效回答数 |
| 重复填写 | 按成功提交的回答次数计算；同一用户的多份答卷可贡献多次，不称作去重人数 |
| 选择题比例 | 各选项次数除以有效回答数，多选比例总和可超过 100% |
| 零样本 | 没有有效回答时比例、数字最小值/最大值/均值返回 `null`，页面显示“暂无”；有效数字 0 正常显示为 0 |
| 目录标题 | 使用本人问卷引用过的最高版本题干，不显示未经本人引用的源题新版；目录按题目 ID 升序，版本按版本号倒序 |

源题所有者或共享接收者不能汇总他人问卷的答卷。读取统计不要求仍持有原题共享授权，也不要求原题或版本处于可新增选用状态；信息来自本人问卷保存的可信快照。撤权、归档及源记录不可读取均不妨碍本人既有问卷的统计。统计响应不返回填写者、参与凭据、来源问卷明细或管理字段。

旧结构问卷继续使用原整卷统计，不混入新版题目目录。需要新版能力时可明确选择[旧问卷迁移工具](12_旧问卷显式迁移说明.md)；迁移不会把不同旧卷的同文题自动合并。

## 接口与实现

| GET 路径 | 返回 |
|---|---|
| `/api/question-statistics` | 本人引用题目目录，支持 `search/page/pageSize` |
| `/api/question-statistics/{question_id}/versions` | 本人引用过的版本分页 |
| `/api/question-statistics/{question_id}/versions/{version_id}` | 精确版本的汇总及该题型指标 |
| `/api/question-statistics/{question_id}/versions/{version_id}/values` | 文本或数字原值分页；选择题返回 `409 STATISTIC_VALUES_UNSUPPORTED` |

没有本人引用、版本不属于该题或不可见目标统一返回 `404 NOT_FOUND`；分页越界返回空页并保留总数。四项接口均只读，不创建或补全源题记录。最终响应模型及错误结构见[2.2 完整 OpenAPI](附件/openapi-v2.json)。

实现位于 [statistics_service.py](../01_代码/backend/app/statistics_service.py) 和 [statistics_contracts.py](../01_代码/backend/app/statistics_contracts.py)。MongoDB 服务端聚合仅关联目标用户的匹配问卷及答卷；相邻 `$lookup/$unwind` 利用 [MongoDB 官方说明的合并优化](https://www.mongodb.com/zh-cn/docs/v8.3/core/aggregation-pipeline-optimization/)，避免把整份问卷的全部回答装成一个大数组。聚合输出只保留有界的汇总、选项或当前页原值。

数字总和使用 Decimal128，中间求和后先在十进制中除以有效回答数，再转换为响应数字，避免有限输入接近浮点上限时中间和溢出。原值不加载到 Python 内存后再分页。

## 验证

[统计接口测试](../01_代码/backend/tests/test_cross_survey_statistics.py) 的 34 项用例通过：四题型、不同本地 ID 的跨卷汇总、版本/恢复/副本隔离、同人多次回答、空及跳过、零分母、字面搜索和稳定分页、本人范围、撤权后快照、缺少源记录、旧结构兼容、`±1.7e308` 的数字均值，以及 1,801 份累计超过 16 MiB 的有效历史数据聚合和原值分页。

前端新增 3 项真实浏览器场景，已与既有 9 项一起通过全量 12 项验收；含桌面、390px 移动端、慢请求切换、目录及原值分页、权限和恢复隔离。完整回归结果和证据位置见[测试说明](../03_测试/README.md)。
