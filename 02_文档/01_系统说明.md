# 问序｜系统说明

## 1 系统目标与角色

问序（FORM & FIELD）是基于 MongoDB 的在线问卷系统，覆盖问卷设计、发布分享、登录填写和答卷统计，支持桌面及移动端访问。所有账号都可以创建问卷，也可以通过分享链接填写问卷；权限取决于当前访问的问卷，没有单独的管理员角色。

| 使用身份 | 可以进行的操作 | 权限范围 |
|---|---|---|
| 未登录访问者 | 注册、登录 | 登录后才能访问分享问卷 |
| 问卷创建者 | 编辑、发布、分享、关闭问卷，查询答卷与统计 | 仅限自己创建的问卷 |
| 登录填写者 | 逐题填写、返回修改、确认提交 | 须满足开放时间与重复填写规则 |

匿名是整份问卷的设置，**匿名问卷仍要求登录，匿名答卷不保存直接账号引用**。禁止重复填写时另存参与记录；这种分离不保证底层日志或时间信息无法用于推断身份。

| 层次 | 技术与职责 | 代码入口 |
|---|---|---|

| HTTP 接口 | FastAPI；路由、登录依赖、请求限制和错误响应 | [main.py](../01_代码/backend/app/main.py) |
| 请求模型 | Pydantic；字段类型与容量 | [models.py](../01_代码/backend/app/models.py) |

| 领域规则 | 题型校验、答案规范化和跳转路径 | [domain.py](../01_代码/backend/app/domain.py) |

构建后的前端由后端同源托管，开发时可通过 Vite 代理访问后端。提交事务要求 MongoDB 副本集。

## 3 功能与使用流程

| 步骤 | 操作与规则 |
|---|---|
| 注册登录 | 首次使用自行注册，没有预置账号。注册后前端自动调用登录；登录凭据保存在当前浏览器会话中 |
| 新建草稿 | 设置标题、说明、截止时间、匿名方式和是否允许重复；配置单选、多选、文本、数字题及校验、跳转规则，手动保存 |
| 发布分享 | 至少一道合法题目才能发布；分享地址为 `/survey/{publicId}`。发布后冻结题目结构及填写设置，开放期间仍可改标题、说明和未来截止时间，或取消截止时间 |
| 逐题填写 | 按实际路径作答；跳转只向后或结束，首条命中优先。被跳过的必答题无需回答 |
| 返回修改 | 仅查看或规范化后答案相同，保留后续答案；实际修改前题并继续时清空后续答案，重新填写 |
| 确认提交 | 服务端重算路径与校验，只有成功提交才持久化答卷；提交后不能修改或撤回。结果不确定时，页面保留原凭据与答案供同次重试 |
| 查看结果 | 创建者可分页查看原始答卷、整卷与单题统计；匿名答卷不展示账号 |
| 结束问卷 | 手动关闭或到期后停止新填写，关闭后配置只读，不能重新开放 |

工作空间支持按标题搜索、状态筛选和分页。草稿编辑、发布与关闭使用 `revision` 防止并发覆盖；冲突时保留本地输入，确认重新加载后才替换。该修订号不是问卷内容历史版本。

**填写者未提交的答案与填写凭据只保留在当前页面内存，不提供刷新或退出后的恢复。** 允许重复填写时，可在成功页主动“再填一份”；网络重试使用原次提交，不另开填写。

## 4 主要限制与边界

| 项目 | 当前实现 |
|---|---|
| 重复填写 | 默认同账号只能成功提交一次，可在发布前允许重复 |
| 题目与规则 | 每卷最多 100 题，选择题 2～50 项，每题最多 20 条跳转；文本题不支持条件跳转 |
| 文本与数字 | 文本答案最多 10000 个 Unicode 码点；数字必须有限，整数使用安全整数范围 |
| 分页 | 页码从 1 开始，默认每页 20，最多 100 |
| 统计 | 只计成功答卷；留空与被跳过题目不计入单题有效回答数；多选选项次数之和可超过回答人数 |
| 截止 | 使用带时区日期，服务端按请求到达时间判断；截止前在途提交与关闭竞争的处理见关键逻辑说明 |

本阶段不包含找回密码、邮件邀请、文件上传、答卷导出、管理员后台或公网运维。登录退出清除客户端凭据，没有刷新令牌或服务端撤销列表。

安装、配置、副本集启动及运行命令见 [代码 README](../01_代码/README.md)。正式提交副本排除了真实配置、依赖目录和本机运行数据；运行后生成的这些内容不应加入提交包。
