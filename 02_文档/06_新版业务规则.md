# 问序新版业务规则

整理日期：2026-10-22。

本文根据第二阶段的八项更新需求，记录三轮讨论中已经确认的业务规则，作为数据库、接口、页面和验收设计的依据。具体实现见[基础流程](09_基础流程实现说明.md)、[管理能力](10_管理能力实现说明.md)和[跨问卷统计](11_跨问卷统计实现说明.md)，测试结果及证据见[测试说明](../03_测试/README.md)。

状态：业务规则已全部确认，并已在 2.2 实现。以下保留原定稿内容。正式保存的版本一律不可覆盖；未被发布问卷使用的版本同样遵守此规则。

## 1. 核心对象与内容边界

### 1.1 题目、版本与卷内实例

| 对象 | 含义 |
|---|---|
| 题目 | 一个长期稳定的业务身份，用于关联该题的不同版本 |
| 题目版本 | 某次保存的具体题目内容，记录其来源版本；同一道题可以保留多个版本 |
| 卷内实例 | 某个题目版本在具体问卷中的一次引用，承载该问卷的设置 |
| 独立副本 | 基于已有题目版本另存的新题目，拥有新的题目身份和所有者，并保留来源信息 |
| 题库 | 用户整理题目的个人分类容器，不承担题目所有权或共享授权 |

题干相同不代表题目身份相同。独立副本与来源题目不属于同一个统计对象。

### 1.2 字段归属

| 属于题目版本 | 属于卷内实例 |
|---|---|
| 题型、题干、题目说明、选项、答案校验限制 | 是否必答、题目顺序、跳转规则 |

跳转目标属于具体问卷，不随题目跨问卷复用。卷内实例需要稳定标识，以供答案和跳转引用；具体字段在数据模型阶段确定。

## 2. 问卷引用与版本选择

1. 问卷固定引用具体题目版本，不自动跟随题目的最新版本。
2. 草稿问卷可以主动替换所用版本；替换后需要检查该问卷的校验和跳转配置。
3. 已发布或已关闭问卷保持原版本及冻结的内容，不因题目更新、恢复、共享变化或归档而改变。
4. 同一道题在一份问卷中最多出现一次，包括该题的不同版本。
5. 在同一问卷中将 v1 更新为 v2，属于替换原引用，不能同时保留这道题的两个实例。

2026-10-23 补充换版交互：选择版本时明确说明字段归属。换到不同版本使用新的题型、题干、说明、选项和答案校验，保留本卷必答设置、卷内 ID 和位置；其他题指向本题的跳转保留。本题自身的跳转规则全部重设，不自动推断条件与新选项的对应关系。存在本题跳转时，预览列出被移除的旧选项及将清空的规则数，用户二次确认后才修改本地草稿，手动保存后生效；取消保留原版本及全部配置。再次查看当前版本不执行换版，也不清空规则。

独立副本具有不同题目身份，不按题干相同判断为同一道题。

## 3. 历史版本与恢复

正式保存的版本内容不可覆盖，保存内容修改时创建新版本，即使旧版本尚未被发布问卷使用。编辑中尚未保存的内容可以自由调整；引用旧版本的其他草稿保持原内容。

历史版本保留来源关系，并同时提供以下两个操作。

| 操作 | 场景 | 结果 |
|---|---|---|
| 选用历史版本 | 制作草稿问卷时希望使用旧版题目 | 直接引用旧版本，不生成版本 |
| 恢复为新版本 | 管理题目时希望将旧内容重新作为新版使用 | 以旧版本内容创建新版本，并记录恢复来源 |

例如，已有 v1、v2、v3 时：

- 在草稿中选用 v1，题目仍保留 v1、v2、v3。
- 以 v1 恢复生成 v4，v4 内容与 v1 相同，历史版本继续保留。
- 恢复不会替换既有问卷的引用，用户仍需在草稿中主动选择版本。
- 恢复生成的新版本与原版本分别统计，即使内容相同。

为原题创建版本和恢复原题，只能由原题所有者操作。共享接收者可以选用已授权历史版本，或另存为自己的独立题目。

## 4. 所有权、共享与撤权

### 4.1 所有权与操作权限

每道题只有一个所有者。

| 操作 | 题目所有者 | 获得共享的用户 |
|---|---|---|
| 查看、选用可使用的版本 | 可以 | 授权有效时可以 |
| 为原题创建版本、恢复旧版 | 可以 | 不可以 |
| 共享原题、撤销授权 | 可以 | 不可以 |
| 归档原题 | 可以 | 不可以 |
| 另存为独立题目 | 可以 | 授权有效时可以 |

问卷中的必答、顺序和跳转由该问卷创建者管理，并继续受发布冻结规则约束。

### 4.2 共享范围

1. 共享给指定的已注册用户。
2. 授权覆盖整道题，包括已有历史版本和后续新增版本。
3. 授权有效期间，接收者可以查看并选用可使用的版本。
4. 新版本对接收者开放，不表示自动替换其问卷中的旧引用。
5. 接收者不能代替原题所有者向其他用户授予原题权限。

### 4.3 独立副本与再次共享

1. 接收者可以将已授权题目版本另存为自己的独立题目。
2. 独立副本具有新的题目身份，由接收者拥有并管理，保留来源题目和来源版本信息。
3. 独立副本的所有者可以修改自己的题目、管理版本并继续共享该副本。
4. 原题所有者撤销共享，不收回已形成的独立副本。
5. 独立副本的数据与来源题目分别统计。

### 4.4 撤销共享

撤权限制后续新增使用，保留撤权前已经保存的问卷引用。

| 撤权后的行为 | 规则 |
|---|---|
| 已发布问卷继续使用原版本 | 允许 |
| 已保存的草稿保留原引用并继续发布 | 允许 |
| 在新问卷中引用原题 | 不允许 |
| 给已有问卷新增原题，或切换其引用版本 | 不允许 |
| 再次将原题另存为独立题目 | 不允许 |
| 管理、共享撤权前已另存的独立副本 | 允许 |
| 统计自己已有问卷的数据 | 允许 |

复制问卷形成新的题目引用，需要重新检查使用权限。撤权后的已有引用仅保留该问卷所需内容，不因此继续取得原题的完整版本访问权限。

## 5. 题库、归档与引用查询

### 5.1 题库

1. 题库为个人分类容器，共享授权在题目层面处理。
2. 同一道题可以加入多个题库，不因分类而复制题目。
3. 用户可以整理自己的题目以及当前有权使用的共享题。
4. 加入、移出题库不改变题目所有权或共享权限。
5. 删除题库只删除分类容器及分类关系，不删除题目及版本。
6. 从题库选题时仍选择具体版本，并检查题目使用权限。

### 5.2 归档

1. 正式保存的题目和版本采用归档方式移除，保留历史与来源关系。
2. 归档后停止新增选用，已有问卷保留所用内容。
3. 归档不影响已有问卷的答卷及统计解释。

### 5.3 引用查询与信息边界

1. 题目所有者可以查看引用数量。
2. 对自己有访问权限的引用问卷，展示问卷名称、状态和所用版本。
3. 对其他用户的问卷，仅展示引用数量，不展示问卷名称或答卷内容。
4. 拥有题目或获得题目共享，不代表拥有使用该题的问卷及答卷权限。

## 6. 跨问卷统计

### 6.1 权限与分组

1. 统计范围为当前用户有权查看答卷的问卷；当前业务中仅限自己创建的问卷。
2. 题目所有者不能因为别人使用其题目，就汇总其他用户的答卷。
3. 同一道题的同一版本，可以跨上述问卷汇总。
4. 不同版本分别展示，不混合计算。
5. 恢复生成的新版本与旧版本分别统计，即使内容完全相同。
6. 独立副本与来源题目分别统计。
7. 撤权或归档后，用户仍能统计自己已有问卷的数据。

### 6.2 计数与指标

1. 只统计成功提交的答卷。
2. 留空或被跳过的题目不计入有效回答数。
3. 按回答次数统计，不做跨问卷人数去重；同一用户成功提交多份答卷，可以贡献多次回答。
4. 同卷同题最多一次，单份答卷对同一道题最多贡献一次回答。
5. 选择题展示各选项次数和比例；比例以该版本的有效回答数为分母。
6. 多选题的各选项比例之和可以超过 100%。
7. 数字题展示有效回答数、最小值、最大值和均值。
8. 文本题分页查看回答。

## 7. 代表性验收场景

| 场景 | 预期结果 |
|---|---|
| A 问卷引用 v1，题目新增 v2 | A 保持 v1；草稿只有主动操作后才切换版本 |
| 尚未被发布问卷使用的 v1 被修改并保存 | 创建新版本，其他草稿引用的 v1 内容保持原样 |
| 同卷已有某题 v1，再添加该题 v2 | 拒绝重复添加；可以替换原引用 |
| 草稿选用历史 v1 | 不产生额外版本 |
| 从 v1 恢复，当前最高版本为 v3 | 新增 v4，记录恢复来源，旧版本及问卷引用保留 |
| 整题共享后，所有者新增版本 | 授权有效的接收者可以选用新版本，已有引用不自动更新 |
| 接收者另存副本并共享给第三人 | 副本具有独立身份，由副本所有者管理 |
| 撤权前已保存引用的草稿尝试发布 | 允许保留原引用并发布 |
| 撤权后尝试新增引用或另存原题 | 拒绝 |
| 原题撤权后，接收者管理已有独立副本 | 允许 |
| 删除题库 | 题目、版本及问卷引用保留 |
| 所有者查看别人使用原题的情况 | 可见引用数量，不可见无权访问的问卷详情及答卷 |
| 同一版本出现在自己的多个问卷中 | 汇总成功提交答卷中的有效回答 |
| 同一个人填写两个问卷，各回答该版本一次 | 计为两次回答，不称为两名独立用户 |
| 多选题有两份有效回答，每份均选择 A、B | A、B 各两次，各占 100%，比例之和为 200% |
| v4 恢复自 v1，或另存副本内容相同 | 分别统计，不因内容相同合并 |

## 8. 定稿与后续设计

三轮业务规则及正式保存版本的冻结时点均已确认，本文无待定业务规则。

后续设计需要将规则落实为数据结构、接口权限、事务边界和验收用例；技术方案不能放宽已确定的版本不可覆盖、问卷固定引用、撤权保留既有使用和统计权限边界。
